# Perbandingan Materi yang Diajarkan: SBY vs Sentul — Message 7, 8, 9

## Latar Belakang

Dokumen ini dibuat untuk kebutuhan internal PIC (Person-in-Charge) per wilayah, membandingkan apa yang **benar-benar diajarkan secara lisan** di kelas Truth Message 7, 8, dan 9 antara instance Surabaya (SBY, trainer Paulus Oenjoyo) dan instance Sentul (trainer Br. Ronal). Kedua instance direkam dari sesi kelas yang berbeda, dengan trainer berbeda, dan cakupan yang jauh berbeda satu sama lain — meskipun keduanya seharusnya mengajarkan poin outline resmi yang sama.

Sumber data adalah dokumen **Tahap 1 ("Session Outline")** masing-masing instance — catatan paling granular tentang apa yang benar-benar disampaikan trainer di kelas (bukan apa yang seharusnya diajarkan menurut outline). Enam file sumber:

- `messages/M07/Truth_M07_SBY_SessionOutline.md` (29 poin transkrip, Paulus Oenjoyo) vs `messages/M07/Truth_M07_SENTUL_SessionOutline.md` (18 poin transkrip, Br. Ronal)
- `messages/M08/Truth_M08_SBY_SessionOutline.md` (12 poin) vs `messages/M08/Truth_M08_SENTUL_SessionOutline.md` (17 poin)
- `messages/M09/Truth_M09_SBY_SessionOutline.md` (14 poin) vs `messages/M09/Truth_M09_SENTUL_SessionOutline.md` (13 poin, 5 di antaranya adalah materi *carryover* Message 8 — lihat catatan khusus di bagian Message 9 dan Message 8 di bawah)

Tabel-tabel di bawah disusun **berdasarkan struktur outline resmi** (dari `Outline Truth 1st yr 2023 (Eng/ID).pdf`, mis. I, I.A, I.B, II.A.1, dst.), bukan berdasarkan penomoran ad-hoc masing-masing transkrip — karena kedua transkrip menomori poin mereka sendiri secara berbeda.

**Legenda:**
- ✅ = diajarkan (dengan bukti kutipan di transkrip) — ❌ = tidak diajarkan
- **🟰 SAMA** = kedua kampus mengajarkan poin ini (meski sudut pandang/kedalaman bisa berbeda — dicatat di kolom Catatan)
- **Hanya SBY** / **Hanya Sentul** = hanya satu kampus yang mengajarkan
- **Tidak diajarkan** = kedua kampus sama-sama melewatkan poin ini

## Ringkasan Keseluruhan (Message 7-9)

**Takeaway utama untuk PIC:**

1. **Pola konsisten di ketiga message: SBY selalu lebih lengkap.** Di tidak satu pun dari tiga message ini Sentul mengajarkan sesuatu yang SBY lewatkan ("Hanya Sentul" = 0 di ketiganya). SBY secara konsisten menuntaskan 90%+ outline resmi per message (hanya melewatkan 1-2 sub-poin kecil per message), sementara Sentul secara konsisten hanya menuntaskan sekitar 30-60% tergantung message.
2. **Akar masalahnya adalah manajemen waktu di kelas Sentul, bukan kurangnya niat.** Di ketiga message, trainer Sentul menghabiskan porsi signifikan waktu kelas untuk materi latar belakang/recap/ilustrasi sendiri (walkthrough Roma 1-11 di Message 7; walkthrough 11 masalah Korintus dan ilustrasi "kotak-mustika"/"Hambalang" di Message 8; devosi/rencana baca Alkitab pribadi di Message 9) sebelum sempat membuka outline resmi — sehingga waktu untuk materi outline aslinya menjadi tersisa sedikit dan sering terpotong.
3. **Ada satu pola positif:** materi Message 8 poin IX dan X (pengurapan/meterai dan tulisan tinta/cermin), yang sempat tertunda di sesi Message 8 Sentul, **akhirnya tetap disampaikan** — hanya bergeser ke awal rekaman sesi Message 9. Ini menunjukkan trainer Sentul sadar akan celah dan berusaha menutupnya, meski dengan konsekuensi mengurangi waktu untuk outline Message 9 sendiri.
4. **Implikasi praktis:** jika PIC menerima pertanyaan dari trainee Sentul terkait Message 7 II.A.2-II.B.2 (Roma 14-16 bagian tengah), Message 8 bagian pengudusan (V) dan Anak Domba Paskah (VII), atau Message 9 "batu permata" (I.B), karunia rohani (II), dan dua ayat penutup soal jerih lelah (V.A/V.B) — materi-materi ini memang belum pernah disampaikan secara lisan di kelas Sentul, dan trainee mungkin perlu diarahkan untuk belajar mandiri dari outline/referensi tertulis.
